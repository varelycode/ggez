# Working agreement

1. Plan: create a blank Brief. Fill Slice and Outcome, then add 1–5 direct Context sources with reasons or the exact no-context statement. Approve before tasks.
2. Tasks: edit and approve tasks. Generate runner files from that approved copy. Later edits need fresh approval.
3. Build: test each task and set its fixed Result. Verified pauses after each task; Unverified continues after tests. Stop on failures or blockers.
4. Finish: check the Brief acceptance list. Only the user checks final acceptance.
