# Working agreement

1. Planning: create a blank Brief. You fill the two required sections, Slice and Outcome, in one pass. Ask Codex for help as needed; approve before tasks.
2. Tasks: Edit Markdown tasks with stable IDs. Generate Ralph JSON, check IDs and content hashes, then approve the revision before building.
3. Build: test one task, then pause for your review. Unverified skips human checkpoints; tests stay. Stop on failures or blockers.
4. Finish: produce Evidence and Review; address feedback.
