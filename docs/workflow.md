# Working agreement

1. Plan: fill Goal, Why now, result, and Context. Example is optional. Revise, then approve.
2. Tasks: generate them from the Brief. Revise, then approve.
3. Build: test each task and set its Result. Verified pauses per task; Unverified continues after tests.
4. Revise: changed definitions need fresh approval. A changed Brief makes older tasks stale.
5. Finish: run `ggez check`, then review the Brief acceptance list. Only the user accepts the outcome.
