# Working agreement

1. Planning: create a blank Brief. You fill Slice and Outcome in one pass; approve before tasks.
2. Tasks: edit and approve Markdown tasks. Generate runner files only when needed, from that approved copy. Later edits need fresh approval before use.
3. Build: test each task and set its fixed Result. Verified pauses after each task; Unverified continues after tests. Stop on failures or blockers.
4. Finish: check the Brief acceptance list. Only the user checks final acceptance.
