# Working agreement

1. Plan: fill Slice, Outcome, and Context. Run `ggez revise brief`, then approve that revision.
2. Tasks: generate tasks from the Brief. Run `ggez revise tasks`, then approve that revision.
3. Build: test each task and set its fixed Result. Verified pauses after each task; Unverified continues after tests.
4. Revise: changed definitions need a new revision and approval. A changed Brief makes older tasks stale.
5. Finish: run `ggez check`, then review the Brief acceptance list. Only the user accepts the outcome.
